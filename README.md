# Exam board

A single-page Kanban-style revision board for my Semester I courses (Discrete Math, AI, DBMS, Networks, Embedded Systems), with a weekly study rotation.

- Move topics through To cover, Learning, Practising and Exam-ready.
- Per-course readiness strips show which course is lagging.
- Progress is saved in the browser (localStorage).
- Static site: one `index.html`, no build step.

## Run locally

Open `index.html` in a browser.

## Deploy

Import the repository on Vercel with the "Other" framework preset and no build command.
